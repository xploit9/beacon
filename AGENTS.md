## Reference-first integration
Hermes Relay is the primary implementation reference for the coordinator and every worker. Inspect the actual corresponding Relay source before building a replacement. Reuse proven components, protocol behavior and verified callback work where they fit; adapt to Cypher's existing architecture, naming, visual identity, navigation and settings rather than adding a parallel subsystem. New code needs a concrete compatibility or safety reason. Do not obfuscate, perform cosmetic rewrites to conceal derivation, misstate originality, or remove required copyright/license notices. Retain applicable MIT/GPL notices and truthful third-party attribution. Protocol identifiers and legitimate Relay integration names must remain correct. Record reference files actually inspected, reused behavior, and necessary adaptations in the project-local run handoff; keep operational handoffs out of Git.
